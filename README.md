# Full-Stack E-Commerce MVP

This project is currently in development and new features will be added incrementally.

## Features

* Mobile-first responsive UI
* Product listing from MongoDB
* Product details page
* Add products to cart
* Cart stored in database
* Checkout page
* Order creation API
* Cart cleared after order placement
* Cash on Delivery payment option

---

## Application Flow

1. Browse products
2. View product details
3. Add items to cart
4. Proceed to checkout
5. Enter shipping details
6. Backend creates order in MongoDB
7. Cart is cleared after order placement
